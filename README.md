## 🚀 About The Project

**Github Void Explorer** is a high-fidelity, interactive 3D WebGL experience. Designed as a floating journey through a digital galaxy, this project reimagines the GitHub platform, its tools, and the developer community as an expansive, explorable cosmic universe.

Users scroll through the void to discover floating islands, astronaut avatars, and interactive 3D components, all powered by React Three Fiber and GSAP.

### ✨ Features
- **Immersive 3D Environment:** Fully rendered WebGL scenes, custom GLTF/GLB models, and Draco compression.
- **Scroll-Driven Storytelling:** Smooth, physics-based scrolling animations using Lenis and GSAP.
- **Dynamic Post-Processing:** Advanced visual effects like blooming, color overlays, and soft shadows.
- **Glassmorphism UI:** Sleek, modern overlays that stay out of the way while providing access to socials and links.
- **Optimized Performance:** Lazy-loaded 3D assets and dynamic decoder loading for seamless frame rates.

## 💻 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need a local web server to serve the assets correctly (to bypass browser CORS restrictions on `file://` protocols).

* Node.js & npm (or python)
  ```sh
  npm install -g live-server
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Sunil56224972/Github-Void-Explorer-.git
   ```
2. Navigate into the directory
   ```sh
   cd Github-Void-Explorer-
   ```
3. Start a local server
   ```sh
   live-server
   ```
   *(Alternatively, use `python -m http.server 8000`)*
4. Open your browser and navigate to `http://localhost:8080` (or `8000`).
